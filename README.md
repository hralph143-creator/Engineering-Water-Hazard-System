# 智域水盾——工程机械水害智能感知与安全作业辅助系统

智域水盾面向露天矿山、土方施工、施工道路、采坑、低洼作业面和大型工程施工区域，利用 Sentinel-1 SAR 遥感影像与 U-Net 像元级语义分割模型识别积水及异常水体空间范围，并提供任务追踪、双时相变化分析、规则化基础水害辅助研判、AI解释和成果导出。

系统定位为工程机械智能施工体系中的环境水害感知与安全作业辅助层。识别和提示结果用于辅助分析，不替代现场检查、工程安全鉴定或施工单位正式安全决策。

完整功能和能力边界见 [系统功能说明.md](系统功能说明.md)。

## 1. 当前真实能力

- 当前正式支持 Sentinel-1 SAR VV/VH 双波段 GeoTIFF，以及单波段、带 CRS 的 GeoTIFF DEM。
- 支持文件校验、CRS与空间元数据检查、SHA256去重和批量导入。
- 支持单景及批量积水识别、任务队列、状态跟踪和历史追溯。
- 输出积水概率图、积水分布图、像素统计、平均置信度和基础水害提示。
- 支持 T1/T2 双时相新增积水、持续积水、消退积水和持续非积水分析。
- 支持 GeoTIFF、PNG、CSV、HTML 和 PDF 成果。
- 支持基于结构化识别结果的智盾助手辅助解读。
- 支持基于变化分析的透明规则研判，输出低、中、高三级“水害关注”等级及标准原因码。
- 支持高水害关注区域、重点巡检区域和一般区域三类空间成果；一般区域不等于安全作业区。
- 支持 DEM 高程统计、度制坡度、相对低高程分区，以及施工区域、风险区和设备位置的地形辅助分析。

DEM、人工/CSV降雨观测、无人机正射影像、施工区域和工程机械位置快照均已真实接入；系统不接入无人机实时视频、设备实时定位或自动控制。

## 2. 系统架构

浏览器或桌面窗口通过本机 HTTP API 使用系统。Vue 负责项目工作台、分析页面与成果展示；FastAPI 负责业务接口、验证、任务队列、报告、诊断和备份；SQLAlchemy/SQLite 保存结构化业务记录；Rasterio、NumPy、PyTorch 与 U-Net 执行本地栅格处理和积水识别。桌面发行版由 PySide6 WebEngine 承载，并把前端静态资源和本地 API 一并封装。

## 3. 技术组成

- 前端：Vue 3、TypeScript、Naive UI、ECharts、Vite。
- 后端：FastAPI、SQLAlchemy、SQLite。
- 遥感与AI：Rasterio、NumPy、PyTorch、U-Net。
- 桌面端：PySide6 WebEngine、PyInstaller、Inno Setup。

## 4. 运行环境

- Windows 10 或 Windows 11；
- Python 3.10–3.11；
- Node.js 20 LTS 或更高版本；
- npm 10 或更高版本；
- Microsoft Edge，用于生成 PDF 报告；
- 可选：支持 CUDA 的 NVIDIA 显卡。

没有可用显卡时可以使用 CPU，但推理速度会降低。

## 6. 系统配置

主配置文件为 `configs/app.yaml`，主要包含：

- 模型权重和 SAR 预处理统计路径；
- 模型评估与训练历史文件；
- 上传目录、成果目录和 SQLite 数据库路径；
- 默认积水识别阈值；
- 基础水害提示阈值；
- 辅助研判规则版本及新增、持续、净变化触发阈值；
- 地形分析规则版本及相对低高程分位阈值；
- 推理设备策略。

基础水害提示沿用现有积水识别占比规则，只是展示层辅助提示，不代表真实水深或正式施工风险等级。

辅助研判规则采用 `water-risk-v1` 触发式规则，不计算未经标定的风险分数。默认参数用于科研与工程场景验证，不属于行业强制安全标准。正式关注等级由规则引擎生成，AI只能解释，不能覆盖或重新分类。

默认变化参数为：新增积水进入关注 1%、高关注 5%；持续积水进入关注 2%、高关注 8%；净扩大 1%、净缩小 -1%。当前积水因素复用基础水害提示的中、高阈值。任一高关注条件触发高水害关注；未触发高关注但达到当前、新增、持续或净扩大关注条件时为中水害关注，其余为低水害关注。

### AI辅助研判

智盾助手调用兼容 OpenAI Chat Completions 协议的模型服务。推荐在“系统设置 → AI辅助研判”配置接口地址、模型名称、API Key、超时、温度和最大输出 Token。

API Key 只提交到本机后端，并在 Windows 上通过当前用户的 DPAPI 加密保存；查询接口不会返回密钥明文。未配置AI服务时，数据管理、积水识别、变化分析和报告功能仍可正常使用。

智盾助手仅接收系统生成的结构化统计，不发送 GeoTIFF、PNG、栅格像元或本地路径。它不得虚构水深、机械位置、道路安全状态、边坡结论或未来灾害预测。

### 风险研判中心

风险研判中心以已完成的时空变化分析为来源，使用当前积水、新增积水、持续积水、消退积水和净变化执行透明规则研判。标准原因码记录当前积水、新增积水、持续积水、整体扩大或缩小等依据，所有结论可追溯至来源变化分析与规则版本。

空间成果固定为：新增积水和持续积水映射为高水害关注区域，消退积水映射为重点巡检区域，持续非积水映射为一般区域，变化无效像素映射为 NoData。系统不是自动安全决策系统。

### 演示前建议

1. 运行 `run.bat --check`，确认目录和端口均显示 `OK`。
2. 启动系统，在“系统设置 → 系统诊断与数据保护”中确认数据库、前端资源、模型文件和磁盘状态。
3. 在页面顶部选择演示项目，进入“项目工作流”确认主要环节和项目数据完整度。
4. 演示结束前执行一次“快速备份”。日志位于项目 `logs` 目录；桌面版日志位于 `%LOCALAPPDATA%/ZhiyuShield/logs`。

系统离线运行时，项目、识别、变化、风险、地形、降雨、无人机和作业辅助等本地功能继续可用；只有显式启用且配置完成的 AI 辅助研判需要访问外部模型服务。

### 系统诊断与备份

“系统设置 → 系统诊断与数据保护”可检查数据库、模型、前端资源、数据/输出/日志目录、AI配置、磁盘与端口，并导出脱敏的 TXT 或 JSON 报告。

快速备份使用 SQLite 在线备份机制保存数据库与必要配置；完整备份清单额外记录上传和成果目录的文件数量与总体积，不重复复制大体积原始影像。当前版本不提供自动恢复。需要恢复时，应先退出系统、再次备份当前数据库，核对备份清单后由维护人员手动替换数据库；不得在服务运行中直接覆盖。

## 8. 页面与使用流程

### 施工态势总览

展示环境数据总量、累计分析任务、最新积水占比、基础水害提示、施工项目与区域数量、区域影响统计、最近任务、最新识别成果、积水变化趋势、任务状态和模型状态。所有数字均来自当前数据库和模型服务。

### 施工区域管理

管理施工项目及项目内的采坑、施工道路影响区、低洼区域、作业面、材料/堆场和排水关注区域。区域边界支持标准 GeoJSON `Polygon` 与 `MultiPolygon`，保存时校验边界闭合、坐标数值和 CRS。项目采用归档保留历史；已有水害影响记录的区域不能物理删除。

### 工程机械管理

管理挖掘机、装载机、自卸车、矿卡、推土机、压路机、起重机等工程机械，记录人工或 CSV 导入的位置快照。每条位置必须包含 CRS 和记录时间；系统根据 `equipment-water-link-v1` 将最近位置与所属项目施工区域、风险研判栅格进行确定性关联。位置快照不代表设备实时位置、运动轨迹或机器通信状态。

### 环境数据中心

SAR区导入一至多个可读取的 VV/VH 双波段 GeoTIFF；DEM区导入单波段、带 CRS 的 GeoTIFF，并记录来源、采集日期、分辨率和垂直基准等可选说明。系统检查尺寸、波段、坐标参考系统、Transform、Bounds、NoData 和有限像素，并使用 SHA256 防止同一 DEM 重复入库。

DEM可生成高程预览、度制坡度、相对低高程掩膜和摘要；衍生成果按文件哈希、`terrain-analysis-v1` 与分位参数缓存。地理坐标或非米制水平单位的 DEM 不直接计算坡度，以避免错误结果。

### 积水智能识别

选择已校验影像并设置判定阈值，然后创建单景或批量任务。任务由后端 FIFO 队列顺序执行，关闭浏览器不会终止已提交任务。

### 任务与成果

按数据名称、状态、基础水害提示、日期和批次筛选任务；支持失败重试、完成任务重新识别、成果查看、删除和双时相对比入口。

### 时空变化分析

选择两个已完成结果作为 T1 和 T2。只有 CRS、Transform、Bounds 和尺寸完全一致时才执行像素级变化分析；否则只提供统计对比，不会强制缩放或配准影像。

### AI辅助研判

智盾助手可解释积水占比、识别统计及新增、持续、消退变化，并给出现场复核或巡检优先级建议。内容仅供辅助参考。

### 风险研判中心

选择一条已完成的时空变化分析，生成基础水害关注等级、规则依据、巡检建议和水害关注区域图。选择施工项目后，可将项目内全部启用区域与 `risk_zone.tif` 按真实多边形边界叠加。还可选择当前项目或通用 DEM，对一般区域、重点巡检区域和高水害关注区域分别统计平均高程、平均坡度和相对低高程重叠比例。DEM只增强解释，不修改 `water-risk-v1` 正式等级。结果可查询历史并导出 GeoTIFF、PNG、CSV、HTML 和 PDF。

## 10. 能力边界

- 模型输出是积水或水体空间识别结果，不是真实积水深度。
- 识别置信度不是灾害发生概率。
- 基础水害提示来自整景积水识别占比规则，不是正式施工风险等级。
- 当前不具备设备自动控制、绝对安全路线判断、边坡稳定判定或未来水害精准预测能力。
- 风险研判只覆盖遥感积水这一水害维度；一般区域不代表绝对安全，关注等级不等于施工综合风险等级。
- 作业区域的低、中、高水害影响由 `work-area-impact-v1` 透明规则生成，仅代表该区域与当前水害关注栅格的空间重叠情况，不代表综合施工安全等级。
- 设备水害关联分别展示点位栅格类别与所在区域整体影响；位置超过配置时效后标记为“位置已过期”，不得作为当前设备位置事实。
- 当前未接入设备实时定位、轨迹、速度、油耗、CAN总线、自动调度、路线规划或机械控制。
- 相对低高程只表示当前 DEM 覆盖范围内的相对地形位置，不等于必然积水；坡度也不直接表示工程机械是否能够安全通行。
- 地形分析不预测积水深度、地下水位、真实排水路径、道路承载力、边坡稳定性、滑坡、泥石流或未来洪水。
- 系统是辅助研判系统，不是自动安全决策系统，不得据此直接作出通行、停工或撤离决定。
- 所有成果均应结合现场巡检、地形、气象水文资料和施工安全制度复核。
